# Brickwork 1.2.0

This release brings foundry regions, such as difficult terrain, into Brickwork,
among many other improvements and conveniences.

By default, Brickwork turns an Inkarna shape (but not line) into a region instead of a wall if:
- It uses a colored line instead of a stamp texture
- Has "region", "difficult terrain" or similar things in a layer or group name that it is nested in
- Or has those words in the name of the actual shape object itself

Each of those can be turned off in the new greatly expanded settings menu.

Other features include


Major features include:

- Regions: Import from Inkarnate, create, modify delete like walls, convert regions into walls and vice versa
- Editing terrain wall thickness, including default thickness for non-imported walls
- Foundry Maps Directory: You can now tell Brickwork where your FoundryVTT map image files live, and Brickwork will correctly set the background image for your scene and derive the grid dimensions

Minor features:
- It is now possible to rename walls and groups
- You can change wall-types of all selected wall walls and portals at once
- More convenient wall/portal type-cycling: portals use Door / Secret Door / Window / Disabled; walls skip door types. The sidebar dropdown still offers all types.
- Notify on updates: When a new Brickwork version becomes available, you will be told on startup. You can silence this.
