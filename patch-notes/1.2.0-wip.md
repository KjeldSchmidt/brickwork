# Brickwork 1.2.0 - WIP

This is a work-in-progress and has not yet been released.

Features include:

- (Planned) Flagship Feature: Regions
- (Done) Editing terrain wall thickness, including default thickness for non-imported walls
- (Done) You can now add a foundry maps directory so that you don't need to set the image path again in foundry

Minor features:
- (Done) It is now possible to rename walls and groups
- (Done) Change wall-types of all selected wall walls and portals at once
- (Done) More convenient wall/portal type-cycling: portals use Door / Secret Door / Window / Disabled; walls skip door types. Dropdown still offers all types.
