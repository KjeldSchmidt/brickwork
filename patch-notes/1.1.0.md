# Brickwork 1.1.0

The first proper update adds a bunch of new features for editing imported walls, without changing import/export behaviour at all.

This makes the wall-editing capabilities of Brickwork much more standalone. Previously, only minor adjustments to existing walls where possible. Now, it is a powerful wall-editing tool unto itself.

Features include:

- Undo / redo for map edits
- Eraser tool to delete walls
- Multi-select walls
- Delete walls entirely
- Draw new walls (middle-drag to start; left-click vertices; middle-click / Enter to finish)
- Add and remove wall vertices
- Add and remove portals
